# TDE - K-Means

Trabalho acadêmico de aplicação do algoritmo **K-Means** para análise e agrupamento de dados do mercado financeiro, utilizando o conjunto de dados Dow Jones Index.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Metodologia

- Seleção e preparação dos dados.
- Padronização dos atributos com StandardScaler.
- Aplicação do K-Means com inicialização K-Means++.
- Avaliação dos agrupamentos pelos métodos do Cotovelo e Silhouette.
- Visualização e interpretação dos clusters.
